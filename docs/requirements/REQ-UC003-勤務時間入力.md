# 要件ドキュメント REQ-UC003

## 基本情報

**タイトル:** ユーザーストーリー: 勤務時間入力機能

## ユーザーストーリー詳細

### ストーリー名

勤務時間入力

### ユーザーストーリー

**誰として** 従業員として

**何をしたいか** 日々の勤務時間を記録したい

**その理由** 正確な勤怠管理を行うため

### 受け入れ基準

- 従業員が日付を選択できること
- 従業員が出勤時刻と退勤時刻を入力できること
- システムが入力値を検証すること
- 検証に成功した場合、勤怠情報が保存されること
- 出勤時刻が退勤時刻より前であることをバリデーションすること
- 時刻がHH:MM形式で入力されることをバリデーションすること
- 未来日付の入力を許容すること
- 従業員と日付の組み合わせごとに1件の勤怠レコードとして保存されること

### その他詳細（機能要件/非機能要件）

**機能要件:**
- 日付選択機能
- 出勤時刻入力フィールド
- 退勤時刻入力フィールド
- 入力値バリデーション機能
- 勤怠レコード保存機能（POST /api/attendance）
- 勤怠レコード取得機能（GET /api/attendance/{employeeId}/{date}）
- 勤怠レコード一覧取得機能（GET /api/attendance/{employeeId}）

**非機能要件:**
- データ整合性の保証
- エラーメッセージの分かりやすさ
- 勤怠データの永続化

**業務ルール:**
- 出勤時刻は退勤時刻より前であること
- 時刻は有効なHH:MM形式で入力すること
- 未来日付の入力を許容する
- 従業員と日付の組み合わせごとに1件の勤怠レコードとする
