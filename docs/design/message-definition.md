# メッセージ定義書

システムで使用するすべてのメッセージを一元管理します。

## 命名規則

### メッセージID

* **エラーメッセージ**: `ERR{カテゴリ2桁}{連番3桁}` (例: `ERR01001`)
* **成功メッセージ**: `SUCCESS{カテゴリ2桁}{連番3桁}` (例: `SUCCESS01001`)
* **情報メッセージ**: `INFO{カテゴリ2桁}{連番3桁}` (例: `INFO01001`)
* **警告メッセージ**: `WARN{カテゴリ2桁}{連番3桁}` (例: `WARN01001`)
* **カテゴリ番号**: 機能グループごとに割り当て

## カテゴリ一覧

| カテゴリ | カテゴリ名     | 説明                         |
| -------- | -------------- | ---------------------------- |
| 01       | システム       | システム起動・ヘルスチェック |
| 02       | 勤怠管理       | 勤務時間入力・休暇登録       |
| 03       | バリデーション | 入力値検証                   |
| 99       | 共通           | 共通メッセージ               |

| メッセージID | メッセージ内容                                                       | 説明                     | 関連画面 | 関連要件  |
| ------------ | -------------------------------------------------------------------- | ------------------------ | -------- | --------- |
| INFO01001    | システムを起動しています...                                          | システム起動中の情報表示 | SCR-001  | REQ-UC001 |
| ERR01001     | システムに接続できませんでした。しばらくしてから再度お試しください。 | システム接続エラー       | SCR-001  | REQ-UC001 |
| ERR01002     | システムが一時的に利用できません。                                   | システムメンテナンス中   | -        | REQ-UC001 |

#### REQ-UC002: カレンダー操作

| メッセージID | メッセージ内容                  | 説明                                         | 関連画面 | 関連要件  |
| ------------ | ------------------------------- | -------------------------------------------- | -------- | --------- |
| INFO01003    | カレンダーを読み込んでいます... | カレンダー初期表示時の情報表示（オプション） | SCR-001  | REQ-UC002 |

**備考**: REQ-UC002（カレンダー操作）は、フロントエンド側の状態管理のみで実現されるため、エラーメッセージは発生しません。日付選択や月切り替えは即座に実行され、ユーザーへのフィードバックは視覚的な変更（ハイライト、カレンダー更新）で行われます。

## メッセージ詳細定義

### INFO01001: システムを起動しています...

- **メッセージタイプ**: INFO（情報）
- **カテゴリ名**: システム
- **表示条件**: システム起動時、メイン画面のロード中
- **ユーザーの対処方法**: なし（待機）
- **関連画面**: SCR-001（メイン画面）
- **関連要件**: REQ-UC001
- **HTTPステータスコード**: -（フロントエンド表示のみ）

### ERR01001: システムに接続できませんでした。しばらくしてから再度お試しください。

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: システム
- **表示条件**: システムURLにアクセスしたが、バックエンドAPIに接続できない場合
- **ユーザーの対処方法**: しばらく待ってから再度アクセスする、またはシステム管理者に連絡
- **関連画面**: SCR-001（メイン画面）
- **関連要件**: REQ-UC001
- **HTTPステータスコード**: -（接続エラーのため）

### ERR01002: システムが一時的に利用できません。

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: システム
- **表示条件**: システムメンテナンス中またはヘルスチェックで「DOWN」が返された場合
- **ユーザーの対処方法**: メンテナンス終了まで待機
- **関連画面**: -
- **関連要件**: REQ-UC001
- **HTTPステータスコード**: 503

### INFO01003: カレンダーを読み込んでいます...

- **メッセージタイプ**: INFO（情報）
- **カテゴリ名**: システム
- **表示条件**: カレンダー初期表示時（オプション）。通常は即座に表示されるため、このメッセージは表示されない
- **ユーザーの対処方法**: なし（待機）
- **関連画面**: SCR-001（メイン画面）
- **関連要件**: REQ-UC002
- **HTTPステータスコード**: -（フロントエンド表示のみ）
- **備考**: REQ-UC002の実装では、カレンダーはフロントエンド側で即座に生成されるため、通常このメッセージは不要。将来的にバックエンドから勤怠データを取得する場合にのみ使用される可能性がある

### SUCCESS02001: 勤怠情報が正常に保存されました

- **メッセージタイプ**: SUCCESS（成功）
- **カテゴリ名**: 勤怠管理
- **表示条件**: `POST /api/attendance` が 200 で成功した場合（新規作成・更新とも）
- **ユーザーの対処方法**: なし
- **関連画面**: SCR-002（勤務時間入力フォーム）
- **関連要件**: REQ-UC003
- **HTTPステータスコード**: 200

### SUCCESS02002: 休暇情報が正常に保存されました

- **メッセージタイプ**: SUCCESS（成功）
- **カテゴリ名**: 勤怠管理
- **表示条件**: SCR-003 からの `POST /api/attendance` が 200 で成功した場合（新規・更新）
- **ユーザーの対処方法**: なし
- **関連画面**: SCR-001（メイン画面。SCR-003を閉じた後に表示）
- **関連要件**: REQ-UC004
- **HTTPステータスコード**: 200

### SUCCESS02003: 休暇情報が削除されました

- **メッセージタイプ**: SUCCESS（成功）
- **カテゴリ名**: 勤怠管理
- **表示条件**: 削除確認後の `DELETE /api/attendance/{employeeId}/{date}` が成功した場合
- **ユーザーの対処方法**: なし
- **関連画面**: SCR-001（メイン画面。SCR-003を閉じた後に表示）
- **関連要件**: REQ-UC004
- **HTTPステータスコード**: 204（OpenAPI追加設計。バックエンド未実装）

### ERR02001: 対象日に勤務記録が存在するため、休暇として登録できません

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: 勤怠管理
- **表示条件**: 休暇の `POST /api/attendance` 時、同一従業員・日付に `WORK` レコードが存在し、409（`WORK_RECORD_CONFLICT`）が返された場合
- **ユーザーの対処方法**: 対象日の勤務記録を確認し、必要であれば先に勤務記録を修正する
- **関連画面**: SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC004
- **HTTPステータスコード**: 409（OpenAPI追加設計。バックエンド実装が必要）

### ERR02002: 対象レコードは休暇ではないため削除できません

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: 勤怠管理
- **表示条件**: `DELETE /api/attendance/{employeeId}/{date}` の対象が休暇レコードでなく、409（`ATTENDANCE_RECORD_CONFLICT`）が返された場合
- **ユーザーの対処方法**: 対象日とレコード種別を確認する。勤務記録を削除する操作は本機能では行わない
- **関連画面**: SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC004
- **HTTPステータスコード**: 409（OpenAPI追加設計。バックエンド未実装）

### ERR02003: 休暇レコードが見つかりません。最新の状態を確認してください

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: 勤怠管理
- **表示条件**: 削除APIが 404（`NOT_FOUND`）を返した場合。取得後に別操作で削除された場合など
- **ユーザーの対処方法**: 対象日の最新状態を再取得し、必要に応じて操作をやり直す
- **関連画面**: SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC004
- **HTTPステータスコード**: 404（OpenAPI追加設計。バックエンド未実装）

### ERR03001: 出勤時刻は退勤時刻より前である必要があります

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: 出勤時刻 >= 退勤時刻（同時刻も不可）。フロントエンド検証、またはバックエンドの 400（`INVALID_TIME_ORDER`）
- **ユーザーの対処方法**: 出勤時刻を退勤時刻より前に修正して再保存する
- **関連画面**: SCR-002
- **関連要件**: REQ-UC003
- **HTTPステータスコード**: 400

### ERR03002: 有効な時刻形式で入力してください

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: 時刻が `HH:MM`（00:00〜23:59）形式でない場合（例: `25:00`）。バックエンドの 400（`INVALID_TIME_FORMAT`）
- **ユーザーの対処方法**: `HH:MM` 形式で入力し直す
- **関連画面**: SCR-002
- **関連要件**: REQ-UC003
- **HTTPステータスコード**: 400
- **備考**: 形式エラーと未入力が同時にある場合は本メッセージを優先する

### ERR03003: 出勤時刻と退勤時刻を入力してください

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: 出勤または退勤時刻が未入力の場合。バックエンドの 400（`REQUIRED_TIME`）
- **ユーザーの対処方法**: 両方の時刻を入力して再保存する
- **関連画面**: SCR-002
- **関連要件**: REQ-UC003
- **HTTPステータスコード**: 400

### ERR03004: 休暇種別を選択してください

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: 保存時に休暇種別が未選択の場合。フロントエンド検証で表示し、APIは呼び出さない
- **ユーザーの対処方法**: Sick Leave、Personal Leave、Business Trip のいずれかを選択して再度保存する
- **関連画面**: SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC004
- **HTTPステータスコード**: -（フロントエンド検証）

### ERR03005: 選択された休暇種別が正しくありません

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: リクエストの status が定義済みの勤怠ステータスではなく、バックエンドが 400（`INVALID_ATTENDANCE_STATUS`）を返した場合
- **ユーザーの対処方法**: Sick Leave、Personal Leave、Business Trip のいずれかを選択し直す
- **関連画面**: SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC004
- **HTTPステータスコード**: 400（OpenAPI定義。バックエンド実装が必要）

### ERR03006: 休暇登録では出勤時刻と退勤時刻を指定できません

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: 休暇ステータスで出勤時刻または退勤時刻が指定され、バックエンドが 400（`INVALID_LEAVE_TIMES`）を返した場合
- **ユーザーの対処方法**: 休暇登録では出勤時刻・退勤時刻を空欄にして再度保存する
- **関連画面**: SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC004
- **HTTPステータスコード**: 400（OpenAPI定義。バックエンド実装が必要）

### ERR99001: 予期しないエラーが発生しました。システム管理者に連絡してください。

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: 共通
- **表示条件**: 予期しない例外が発生した場合（catch-allエラー）
- **ユーザーの対処方法**: システム管理者に連絡し、エラー発生時刻と操作内容を報告
- **関連画面**: 全画面
- **関連要件**: 全要件
- **HTTPステータスコード**: 500

### ERR99002: ネットワークエラーが発生しました。接続を確認してください。

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: 共通
- **表示条件**: ネットワーク接続が切断された、またはタイムアウトした場合
- **ユーザーの対処方法**: ネットワーク接続を確認し、再度操作を実行
- **関連画面**: 全画面
- **関連要件**: 全要件
- **HTTPステータスコード**: -（ネットワークエラーのため）
