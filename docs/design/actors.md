# アクター一覧

システムに関与するすべてのアクター（利用者・外部システム）を定義します。

## 命名規則

### アクターID

- **形式**: `ACT-{連番3桁}` (例: `ACT-001`)
- **命名規則**: アクターの種別と役割が明確になるように命名

## アクター一覧

| アクターID | アクター名     | 種別     | 説明                                 | 主な機能・権限                                                             |
| ---------- | -------------- | -------- | ------------------------------------ | -------------------------------------------------------------------------- |
| ACT-001    | 従業員         | ユーザー | 勤怠管理システムを利用する従業員     | システム起動、画面表示、日付選択、勤務時間入力、休暇登録、勤怠レコード参照 |
| ACT-002    | システム管理者 | 管理者   | システムの保守と監視を担当する管理者 | システムヘルスチェック、保守作業、監視                                     |

## アクター詳細定義

### ACT-001: 従業員

* **概要**: 勤怠管理システムを利用して日々の勤怠を記録する従業員
* **役割**: システムへのアクセス、勤怠データの入力・管理
* **関連機能**: システム起動（UC001）、カレンダー操作（UC002）、勤務時間入力（UC003）、休暇登録（UC004）
* **関連画面**: メイン画面（カレンダー表示）、勤務時間入力ダイアログ、休暇登録ダイアログ

### ACT-002: システム管理者

* **概要**: システムの保守と監視を担当する管理者
* **役割**: システムの稼働状況監視と保守作業
* **関連機能**: システムヘルスチェック、保守運用
* **関連画面**: 監視ダッシュボード（将来実装）
