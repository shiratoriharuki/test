## Description

画面設計書において、SCR-002（勤務時間入力フォーム）および SCR-003（休暇登録フォーム）が独立した画面として画面一覧・画面遷移図・画面遷移表に記載されています。しかし、これらの UI はポップアップやモーダルダイアログとして表示される想定であり、通常の画面遷移と同列に扱うと設計表現として不正確です。

この不整合により、実装方針、画面設計レビュー、E2E シナリオ、今後のローレベル設計で認識齟齬が発生するおそれがあります。

---

## Steps to Reproduce（バグの場合）

1. [docs/design/screen-design.md](../design/screen-design.md) の画面一覧を確認する。
2. 同ファイルの画面遷移図を確認する。
3. 同ファイルの SCR-001 の画面遷移表を確認する。
4. SCR-002 / SCR-003 が独立画面として遷移先に定義されている一方で、実際の UI 意図がポップアップ相当であることを確認する。

---

## Expected Behavior（期待される動作）

SCR-002 / SCR-003 がモーダル、ポップアップ、またはオーバーレイとして一貫した表現で設計書に記載され、画面遷移ではなく画面内状態変化またはダイアログ表示として整理されていること。

---

## Actual Behavior（実際の動作）

SCR-002 / SCR-003 が通常の遷移先画面として記載されており、メイン画面から別画面へ遷移するように読める構成になっていること。

3. SCR-001 の画面遷移表や関連説明文を、遷移ではなく画面内操作・状態変化として整合させる。

## Notes（備考）

## Root Cause（原因）

ハイレベル設計の初期整理において、入力フォームを UI 部品ではなく独立画面として分類したため、SCR-001 上のダイアログ表示想定が画面一覧・画面遷移図・関連画面定義に反映されないまま残った。

---

## Solution Applied（実施した対応）

1. [docs/design/screen-design.md](../design/screen-design.md) で SCR-002 / SCR-003 を「独立画面」から「SCR-001 上で開くモーダルダイアログ」に修正。
2. 画面遷移図を、画面遷移ではなくダイアログ表示とクローズの流れとして修正。
3. SCR-001 の遷移表現を「画面遷移・画面内状態変化」に修正し、操作ボタン起点のダイアログ表示に統一。
4. [docs/design/actors.md](../design/actors.md) の関連画面表現をダイアログ表現へ更新。
5. コード変更および E2E 変更は不要と判断。既存実装・既存シナリオと矛盾しないため、テスト実施は不要。
